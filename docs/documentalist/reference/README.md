# Okodukai

Okodukai est un portefeuille éducatif familial. Les enfants gagnent et utilisent des pièces virtuelles et les parents gèrent les activités du foyer. Les simulations servent à expliquer l’épargne et l’investissement.

## Organisation technique

L’API de apps/api gère les soldes, récompenses et autorisations. apps/web fournit l’interface familiale et packages/shared contient les contrats partagés. Les mouvements sont inscrits au journal transactionnel et les opérations sont isolées par foyer.
