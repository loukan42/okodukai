# Okodukai

[Ouvrir Okodukai en ligne](https://okodukai.fr/)

Une tirelire virtuelle pour apprendre à gérer son argent en jouant, pour les enfants de 8 à 12 ans, pilotée par les parents. Les pièces restent virtuelles, sans paiement ni investissement réel.

Le parent organise les quêtes et valide les récompenses. L’enfant suit ses objectifs, économise et découvre l’investissement dans des simulations pédagogiques.

## Code source

Monorepo npm workspaces : l’application web React et Vite se trouve dans `apps/web`, l’API Express et Prisma dans `apps/api`, et les contrats partagés dans `packages/shared`.
